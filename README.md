# 走行評価ロガー（シンプルモード）

評価走行中の気づきを「安全・安心 / 快適 / その他」の3分類と 👍 Good / 👎 Bad で、ボタンを押した時刻と位置情報つきで記録するブラウザアプリです。単一の `index.html` だけで動きます。

このブランチはシンプルモード専用です。詳細な分類（安全T/O・効率T/O・交通違反など）で記録する通常版は `main` ブランチにあります。記録の保存先（localStorage のキー）は通常版と分けているので、同じ端末で両方使っても記録は混ざりません。

## 使い方

0. 画面上部の入力欄に車名を入れると、以降の記録に車名が付きます（次回も残ります）。
1. 上部の「安全・安心 / 快適 / その他」を押すと、その瞬間の時刻と位置で1件記録が始まります。
2. 👍 Good / 👎 Bad を選び、必要ならすぐ下のコメントとシーンを入れて「記録する」で確定します。コメントとシーンは任意です。確定せずに別の分類ボタンを押すと、入力中の内容は記録されません。
3. 一覧の「エクスポート」で、Excel ファイル（.xlsx）のダウンロードか、記録の表のクリップボードへのコピー（タブ区切り）を選べます。未入力のセルは「-」になります。
   「取込」→「追加する」で、このアプリからコピーしたデータ（Excel で編集したものも可）を見出しごと取り込めます。同じ日時・分類・評価・車名の記録は重複として除外します。
4. 画面の一覧は時刻・分類・評価・シーン・地図・コメントだけを表示します（日付と車名はエクスポートに入ります）。各記録には高徳地図で位置を開くリンクが付きます（ピン名は「分類 評価｜コメント｜車名｜日時」）。高徳用の座標は中国国内ではアプリ内で WGS84 → GCJ-02 に変換し、国外ではそのまま渡します。以前の版でコピーした Baidu 地図リンク入りのデータも取り込めます。
5. 一覧の下の「地図」に、位置が取れた記録を高徳地図の上に分類の色で全件表示します。ドラッグで移動、＋／−・ピンチ・ホイールで拡大縮小、「全体」で全件が収まる表示に戻ります。ピンをタップするとその記録の内容と地図リンクが出ます。「画像を保存」で、表示中の地図を凡例つきの PNG にします（iPhone などでは共有シートが開き、「"ファイル"に保存」や AirDrop を選べます。PC ではダウンロード）。地図タイルは API キー不要で読み込みます。

## 言語切替

画面右下のボタンで日本語と中国語（简体）を切り替えます。

## 分類

| 分類 | 評価 |
| --- | --- |
| 安全・安心 | 👍 Good / 👎 Bad |
| 快適 | 👍 Good / 👎 Bad |
| その他 | 👍 Good / 👎 Bad |

シーン（任意）：巡行、発進・加速、減速、右折、左折、Uターン、合流・分岐、ナビLC、追い越し、主動回避、受動回避、横断、ラウンドアバウト

## 公開

位置情報は HTTPS でのみ動作します。Cloudflare Pages で、このブランチを本番ブランチにした別プロジェクトを作って公開します（ビルドコマンドなし、出力ディレクトリ `/`）。

## ホーム画面に追加（オフライン利用）

PWA に対応しているので、ホーム画面に追加するとアプリとして全画面で起動でき、電波がなくても使えます。

- iPhone：Safari で開き、共有 →「ホーム画面に追加」
- Android：Chrome のメニュー →「アプリをインストール」（または「ホーム画面に追加」）

一度開けば、オフラインでも記録・一覧・エクスポート・取込が使えます（位置は GPS で取れます）。オンライン接続が必要なのは次のものだけです。

- 地図：一度表示した範囲の地図タイルは端末に残るのでオフラインでも出ます。未表示の範囲はオフラインだと出ません（地図の上に「オフライン」と表示します）。
- 高徳地図リンク：オフラインのときは開けない旨を表示します。
- フォント：取れないときは端末のフォントで表示します。

新しい版を公開すると、アプリを開いたとき（バックグラウンドから戻ったときも含む）にオンラインなら確認し、自動で再読み込みして最新版にします（「最新版に更新しました」と出ます）。記録の入力中・ダイアログ表示中・文字の入力中は自動では更新せず、画面下に「新しい版があります」と出るので、タップすると更新されます。

**iPhone の注意**：ホーム画面のアプリと Safari とでは保存場所が別です。Safari で記録したデータはアプリ側には出ないので、切り替えるときは Safari 側で「エクスポート」→ 表のコピーをし、アプリ側で「取込 → 追加する」で移してください。

## データの保存先

記録は端末のブラウザ（localStorage）にのみ保存されます（容量不足のときにブラウザが消さないよう、永続保存を要求しています）。ブラウザのデータを消すと失われるため、走行ごとにエクスポートして保存してください。
