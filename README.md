# 走行評価イベントロガー

評価走行中のイベント（安全T/O・効率T/O・交通違反）を、ボタンを押した時刻と位置情報つきで記録するブラウザアプリです。単一の `index.html` だけで動きます。

## 使い方

0. 画面上部の入力欄に車名を入れると、以降の記録に車名が付きます（次回も残ります）。
1. 上部の「安全T/O / 効率T/O / 交通違反」を押すと、その瞬間の時刻と位置で1件記録されます。
2. ② 詳細、③ 道路（高速道／一般道）、④ シーンを選び、「記録を確定」で確定します（メモは任意）。確定せずに分類ボタンやタブを切り替えると、入力中の内容は記録されません。
3. 一覧の「表をコピー」で TSV 形式がクリップボードに入り、Excel にそのまま貼り付けられます。
   「取込」→「追加する」で、クリップボードにあるコピーしたデータ（Excel で編集したものも可）を見出しごと取り込めます。読み取れないときは貼り付け枠が開きます。同じ日時・分類・詳細・車名の記録は重複として除外します。
4. 各記録には Baidu 地図で位置を開くリンクが付きます。Baidu 用の座標は中国国内ではアプリ内で WGS84 → BD-09 に変換し、国外ではそのまま渡します。
5. 「集計」タブでは、日付・車名別とシーン別に、分類・詳細ごとの件数を表で確認できます。日付・道路・車名で絞り込め、表はそれぞれ Excel 用にコピーできます。

## 分類

| 分類 | 詳細 |
| --- | --- |
| 安全T/O | 危険度 高 / 中 / 低 |
| 効率T/O | 発進しない / 加速しない / 車線間違い |
| 交通違反 | 信号無視 / 実線を踏む / 速度超過 / 歩行者保護違反 |
| 不要作動 | 不要減速 / 不要加速 / 不要操舵 |
| その他 | 計測開始 / 計測終了 / システム退出 / システム降級 / システム起動 / その他（道路・シーンの入力なし） |

道路：高速道、一般道

シーン：巡行、発進・加速、減速、右折、左折、Uターン、合流・分岐、ナビLC、追い越し、主動回避、受動回避、横断、ラウンドアバウト

## 公開

位置情報は HTTPS でのみ動作します。GitHub Pages（Settings → Pages → Branch: `main` / root）で公開すると
`https://ryunosuket.github.io/driving-event-logger/` で利用できます。

## データの保存先

記録は端末のブラウザ（localStorage）にのみ保存されます。ブラウザのデータを消すと失われるため、走行ごとにコピーして保存してください。
