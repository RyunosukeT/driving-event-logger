# 走行評価ロガー（シンプルモード）

評価走行中の気づきを「安全・安心 / 快適 / その他」の3分類と 👍 Good / 👎 Bad で、ボタンを押した時刻と位置情報つきで記録するブラウザアプリです。単一の `index.html` だけで動きます。

このブランチはシンプルモード専用です。詳細な分類（安全T/O・効率T/O・交通違反など）で記録する通常版は `main` ブランチにあります。記録の保存先（localStorage のキー）は通常版と分けているので、同じ端末で両方使っても記録は混ざりません。

## 使い方

0. 画面上部の入力欄に車名を入れると、以降の記録に車名が付きます（次回も残ります）。
1. 上部の「安全・安心 / 快適 / その他」を押すと、その瞬間の時刻と位置で1件記録が始まります。
2. ② 評価（👍 Good / 👎 Bad）を選び、必要なら ③ シーンとコメントを入れて「記録を確定」で確定します。シーンとコメントは任意です。確定せずに分類ボタンやタブを切り替えると、入力中の内容は記録されません。
3. 一覧の「エクスポート」で、Excel ファイル（.xlsx、「記録」「日付・車名別」「シーン別」の3シート）のダウンロードか、記録の表のクリップボードへのコピー（タブ区切り）を選べます。未入力のセルは「-」になります。
   「取込」→「追加する」で、このアプリからコピーしたデータ（Excel で編集したものも可）を見出しごと取り込めます。同じ日時・分類・評価・車名の記録は重複として除外します。
4. 各記録には Baidu 地図で位置を開くリンクが付きます。Baidu 用の座標は中国国内ではアプリ内で WGS84 → BD-09 に変換し、国外ではそのまま渡します。
5. 「集計」タブでは、日付・車名別とシーン別に、分類・評価ごとの件数を表で確認できます。日付・車名で絞り込め、表はそれぞれ Excel 用にコピーできます。

## 言語切替

画面右下のボタンで日本語と中国語（简体）を切り替えます。

## 分類

| 分類 | 評価 |
| --- | --- |
| 安全・安心 | 👍 Good / 👎 Bad |
| 快適 | 👍 Good / 👎 Bad |
| その他 | 👍 Good / 👎 Bad |

シーン（任意）：巡行、発進・加速、減速、右折、左折、Uターン、合流・分岐、ナビLC、追い越し、主動回避、受動回避、横断、ラウンドアバウト

## 公開

位置情報は HTTPS でのみ動作します。Cloudflare Pages で、このブランチを本番ブランチにした別プロジェクトを作って公開します（ビルドコマンドなし、出力ディレクトリ `/`）。

## データの保存先

記録は端末のブラウザ（localStorage）にのみ保存されます。ブラウザのデータを消すと失われるため、走行ごとにエクスポートして保存してください。
