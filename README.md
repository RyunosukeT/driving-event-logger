# 走行評価記録

評価走行中のイベント（安全T/O・効率T/O・交通違反）を、ボタンを押した時刻と位置情報つきで記録するブラウザアプリです。単一の `index.html` だけで動きます。

## 使い方

0. 画面上部の入力欄に車名を入れると、以降の記録に車名が付きます（次回も残ります）。
1. 上部の「安全T/O / 効率T/O / 交通違反」を押すと、その瞬間の時刻と位置で1件記録されます。
2. ② 詳細、③ 道路（高速道／一般道）、④ シーンを選び、「記録を確定」で確定します（メモは任意）。確定せずに分類ボタンやタブを切り替えると、入力中の内容は記録されません。
3. 一覧の「エクスポート」で、Excel ファイル（.xlsx、「記録」「日付・車名別」「シーン別」の3シート）のダウンロードか、記録の表のクリップボードへのコピー（タブ区切り）を選べます。未入力のセルは「-」になります。
   「取込」→「追加する」で、クリップボードにあるコピーしたデータ（Excel で編集したものも可）を見出しごと取り込めます。読み取れないときは貼り付け枠が開きます。同じ日時・分類・詳細・車名の記録は重複として除外します。
   一覧の「編集」では位置も直せます。地図のピンをドラッグするか、地図をタップした地点にピンが移り（2本指ピンチで拡大縮小）、「保存」で記録の位置を上書きします（「元の位置に戻す」で取り消し）。位置が取れなかった記録も、地図をタップして位置を付けられます。
4. 各記録には高徳地図で位置を開くリンクが付きます（位置はこのリンク用にだけ保存し、緯度・経度などは表示もコピーもしません）。リンク先のピン名には分類・詳細・メモ・車名・日時が入ります。高徳用の座標は中国国内ではアプリ内で WGS84 → GCJ-02 に変換し、国外ではそのまま渡します。以前の版でコピーした Baidu 地図リンク入りのデータも取り込めます。
5. 「集計」タブでは、日付・車名別とシーン別に、分類・詳細ごとの件数を表で確認できます。日付・道路・車名で絞り込め、表はそれぞれ Excel 用にコピーできます。
   同じ絞り込みで、位置が取れたイベントを高徳地図（AutoNavi）の地図上に分類の色で表示します。ドラッグで移動、＋／−・ピンチ・ホイールで拡大縮小、「全体」で全件が収まる表示に戻ります。ピンをタップするとその記録の内容と高徳地図へのリンクが出ます。「画像を保存」で、表示中の地図を凡例・絞り込み条件つきの PNG にします（iPhone などでは共有シートが開き、「"ファイル"に保存」や AirDrop を選べます。PC ではダウンロード）。地図タイルは API キー不要で読み込み、中国国内の位置は WGS84 → GCJ-02 に変換して重ねます。

## 言語切替

画面右下のボタンで日本語と中国語（简体）を切り替えます。分類・詳細・道路・シーンなどの表示と「表をコピー」の出力が切り替わります（車名とメモは入力したまま）。記録は内部的に日本語名で保存し、取込はどちらの言語のデータも受け付けます。

## 分類

| 分類 | 詳細 |
| --- | --- |
| 安全T/O | 危険度-高 / 危険度-中 / 危険度-低 |
| 効率T/O | 発進しない / 加速しない / 車線間違い |
| 交通違反 | 信号無視 / 実線を踏む / 速度超過 / 歩行者保護違反 |
| 不要作動 | 不要減速 / 不要加速 / 不要操舵 |
| その他 | 計測開始 / 計測終了 / システム退出 / システム降級 / システム起動 / その他（道路・シーンの入力なし） |

道路：高速道、一般道

シーン：巡行、発進・加速、減速、右折、左折、Uターン、合流・分岐、ナビLC、追い越し、主動回避、受動回避、横断、ラウンドアバウト

## 公開

位置情報は HTTPS でのみ動作します。GitHub Pages（Settings → Pages → Branch: `main` / root）で公開すると
`https://ryunosuket.github.io/driving-event-logger/` で利用できます。

## ホーム画面に追加（オフライン利用）

PWA に対応しているので、ホーム画面に追加するとアプリとして全画面で起動でき、電波がなくても使えます。

- iPhone：Safari で開き、共有 →「ホーム画面に追加」
- Android：Chrome のメニュー →「アプリをインストール」（または「ホーム画面に追加」）

一度開けば、オフラインでも記録・確定・一覧・集計表・エクスポート・取込が使えます（位置は GPS で取れます）。オンライン接続が必要なのは次のものだけです。

- 集計の地図：一度表示した範囲の地図タイルは端末に残るのでオフラインでも出ます。未表示の範囲はオフラインだと出ません（地図の上に「オフライン」と表示します）。
- 高徳地図リンク：オフラインのときは開けない旨を表示します。
- フォント：取れないときは端末のフォントで表示します。

新しい版を公開すると、アプリを開いたとき（バックグラウンドから戻ったときも含む）にオンラインなら確認し、自動で再読み込みして最新版にします（「最新版に更新しました」と出ます）。記録の入力中・ダイアログ表示中・文字の入力中は何も表示せずに更新を見送り、次に開いたときに更新します。

**iPhone の注意**：ホーム画面のアプリと Safari とでは保存場所が別です。Safari で記録したデータはアプリ側には出ないので、切り替えるときは Safari 側で「エクスポート」→ 表のコピーをし、アプリ側で「取込 → 追加する」で移してください。

## データの保存先

記録は端末のブラウザ（localStorage）にのみ保存されます（容量不足のときにブラウザが消さないよう、永続保存を要求しています）。ブラウザのデータを消すと失われるため、走行ごとにコピーして保存してください。
